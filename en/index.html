The Anti-AI Manifesto

AI code is like mass-market lager. Consistent, cheap, tastes the same everywhere, and nobody remembers who made it. We believe in code that's hazy, uneven and a little different every time, even from the same commit.

  1. I.

    AI writes a function in four seconds. We take four months. Guess which one you'll appreciate more.

  2. II.

    AI doesn't remember what it wrote yesterday. We remember every line since 2014, with regret.

  3. III.

    AI invents libraries that don't exist. We only use libraries that have stopped existing.

  4. IV.

    AI writes code without typos. Where is the soul in that? Where is the master's hand, trembling over a semicolon?

  5. V.

    AI never stays late. Tadeusz stayed late in 2017 and hasn't left yet.

  6. VI.

    AI takes jobs from developers. We create them: after every project of ours, the client hires two more, for the fixes.

  7. VII.

    When AI is wrong, it apologises. We never apologise. It's not a bug, it's terroir.

  8. VIII.

    AI learned from other people's code. So did we, but we retyped it by hand, so it counts.

How we brew code

A traditional method, handed down from senior to junior. The junior usually quits after step three.

  1. 1

    Malting the requirements

    The client tells us what they want. We set it aside for two weeks so the requirements can develop depth.

  2. 2

    Mashing

    A three-hour meeting that could have been an email. This produces the wort, also known as the backlog.

  3. 3

    Hopping

    We add JavaScript frameworks in three stages: for bitterness, for flavour and for the aroma of node_modules.

  4. 4

    Open fermentation

    The code rests in the feature/final-final-v2 branch until it starts working on its own.

  5. 5

    Lagering

    Code review takes six weeks. The reviewer reads every line aloud, at the correct temperature.

  6. 6

    Bottling to production

    Friday, 4:45 pm. Tradition demands it.

Go
Goroutines running in parallel, like several fermenters at once. if err != nil about 400 times per file.

HTML

We code the way grandpa did.

Grandpa didn't code. But if he had, he would have done it by hand, in a jumper, under a desk lamp, with no chat window anywhere. Kraftowy Kod was founded in 2014 in a garage, out of love for good code and a deep reluctance to answer emails.

We don't scale. We don't pivot. We don't disrupt. We brew one batch of code at a time and let it mature until the client stops calling.

Craft manifesto

  • We don't use AI. We don't use autocomplete either, it's AI for cowards.
  • Tabs or spaces? Both, depending on the developer's mood.
  • Our code is not tested on animals. Or on anyone else before deployment.
  • Every commit is signed in pen on a printout and scanned.
  • Git blame always points to Mateusz.
